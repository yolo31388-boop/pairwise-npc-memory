# 游戏内NPC记忆与对话历史系统

## 项目描述

游戏内NPC记忆与对话历史系统的bug修复项目。核心模块 `ai/npc_memory.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 记忆存储完全没做对话过就忘
- 记忆检索完全没做不能根据上下文检索相关记忆
- 对话历史完全没做只记录最后一条消息
- 情感关系完全没做玩家做了好事NPC也不感激
- 性格演变完全没做NPC永远是同一个性格
